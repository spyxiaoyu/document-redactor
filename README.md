# document-desensitizer

浏览器内文档脱敏/恢复工具（DOCX / PDF / Excel / 图片 / TXT / MD）。

## 命令

```bash
npm install         # 装依赖
npm run dev         # 开发模式（带 HMR，http://localhost:5173）
npm run build       # 类型检查 + 生产构建（输出到 dist/）
npm run preview     # 预览生产构建（http://localhost:4173）
npm run test        # 跑 Vitest
npm run lint        # ESLint
```
